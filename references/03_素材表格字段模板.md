# 漫剧二创 · 素材归集表格字段模板

> 推荐用飞书多维表格搭建（免费、协同、支持公式），也兼容 Notion / 腾讯文档 / Excel。
> 附一份 `素材库示例.csv`，可直接导入作为起点。
>
> **当前为纯卡点无解说模式**：打分时「节奏卡点」「视觉冲击」两项建议原始分各 +0.5（上限5）再算总分——因为没有解说兜底，画面和节奏必须自己扛住全程。

---

## 为什么要建这张表

漫剧二创最耗时的不是剪辑，是"每次都要重新通看原片找爆点"。
这张表的目的：**把爆点分析结果一次性沉淀成可检索的库**，剪辑时直接按等级/类型挑选，不再重复看片。

---

## 字段设计（共 23 个字段）

### A. 基础信息（定位素材）

| 字段名 | 类型 | 说明 | 示例 |
|---|---|---|---|
| 素材ID | 单行文本 | 唯一编号 | M001 |
| 剧名 | 单选 | 哪部漫剧 | 剑尊 |
| 集数 | 数字 | 第几集 | 12 |
| 起始时间码 | 文本 | 爆点开始 | 00:38 |
| 结束时间码 | 文本 | 爆点结束 | 00:42 |
| 时长秒 | 数字 | 片段长度 | 4 |
| 名场面描述 | 多行文本 | 一句话说清画面 | 主角被背叛后当场反杀 |
| 爆点类型 | 单选 | 情绪分类 | 反转/爽点/虐点/燃点/悬念/金句 |
| 文件命名 | 单行文本 | 按规范命名 | 剑尊_EP12_反转_S_0038 |

### B. 五维评分（自动算总分和等级）

| 字段名 | 类型 | 说明 |
|---|---|---|
| 情绪峰值 | 单选/数字 | 1-5 分（权重 30%） |
| 悬念钩子 | 单选/数字 | 1-5 分（权重 25%） |
| 视觉冲击 | 单选/数字 | 1-5 分（权重 20%） |
| 节奏卡点 | 单选/数字 | 1-5 分（权重 15%） |
| 传播潜力 | 单选/数字 | 1-5 分（权重 10%） |
| **总分** | 公式 | 加权求和，见下方公式 |
| **燃点等级** | 公式 | 按总分自动判 S/A/B，见下方公式 |

**总分公式（飞书多维表格）**
```
{情绪峰值}*0.30 + {悬念钩子}*0.25 + {视觉冲击}*0.20
+ {节奏卡点}*0.15 + {传播潜力}*0.10
```
保留 2 位小数。

**燃点等级公式**
```
IF({总分}>=4.2,"S",IF({总分}>=3.5,"A",IF({总分}>=3.0,"B","淘汰")))
```

### C. 使用规划

| 字段名 | 类型 | 说明 | 示例 |
|---|---|---|---|
| 建议用法 | 单选 | 开头钩子/卡点连切/高潮反转/铺垫过渡 | 开头钩子 |
| BPM建议 | 数字 | 适配的鼓点速度 | 128 |
| 授权状态 | 单选 | 已授权/官方鼓励二创/未确认 | 官方鼓励二创 |

> **授权状态为「未确认」的素材禁止使用**，这是矩阵运营的红线。

### D. 使用记录（追踪去重）

| 字段名 | 类型 | 说明 |
|---|---|---|
| 使用版本 | 多选 | V1剧情向/V2人物向/V3名场面向 |
| 使用账号 | 多选 | 已发过哪些账号 |
| 发布日期 | 日期 | 最近一次发布日 |
| 备注 | 多行文本 | 效果反馈、数据表现、复用建议 |

## 建表步骤（飞书多维表格）

1. 新建多维表格，命名「漫剧爆点素材库」。
2. 按上表建立 23 个字段，设置好类型（单选字段先把选项填好）。
3. 「总分」和「燃点等级」字段类型选「公式」，粘贴对应公式。
4. 建议加几个视图，方便不同场景使用：
   - **S级爆点池**：筛选 燃点等级=S，用于找开头钩子
   - **待剪辑队列**：筛选 授权状态≠未确认 且 使用账号为空
   - **已发布复盘**：按发布日期倒序，看哪些爆点数据好
5. 导入 `素材库示例.csv` 作为初始数据（导入时字段类型可能需手动校正）。

---

## 视图与工作流配合

- **工位①**（选题）：把爆点分析结果批量录入表格，填好五维评分，总分和等级自动生成。
- **工位④**（剪辑）：打开「S级爆点池」视图，直接挑素材，不用再通看原片。
- **工位⑥**（分发）：用「使用记录」字段标记已用版本和账号，避免同一爆点在同一账号重复出现。
- **复盘**：一段时间后，在「备注」里记录数据表现，反哺评分模型——如果发现某类爆点数据特别好，可以提高对应维度权重。

---

## 使用提醒

- **五维评分靠人工判断**，AI 打分仅供参考，最终以你实际观察为准。
- **授权状态必填**，矩阵运营被投诉/下架往往就出在这一列被忽略。
- **使用记录及时更新**，否则多账号容易撞车发重复内容导致限流。
- 初期字段不用全填，先填基础信息 + 五维评分 + 授权状态即可跑起来，其余逐步补。
