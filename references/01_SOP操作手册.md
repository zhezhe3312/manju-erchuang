## 核心思路（先记住这一句）

**把最费时的"卡点"固化成一张母版草稿，用 AI 批量预处理文案和字幕，人工只做"套模板 + 换素材 + 微调"。**

不要一条一条从零剪。一周只做 1 张母版，之后所有视频都是这张母版的复制品。

### 无解说后，信息靠什么传递

| 有解说时 | 无解说时（当前） |
|---|---|
| 解说词讲清剧情，画面负责燃 | 画面负责燃 + 讲故事，字幕金句负责点题 |
| 音色区分账号 | BGM / 字幕风格 / 配色区分账号 |
| 人声抓注意力 | 前 3 秒靠「S 级爆点 + 抓人字幕」抓注意力 |

**无解说模式的优势**：省掉整个配音工位，产能更高；不受音色同质化影响；纯卡点更跨平台。
**代价**：前 3 秒没有人声钩子，字幕必须更狠；音效层次要做足，否则容易显得"干"。

## 工位① 批量选题与素材归集

**目的**：一次性备好一周的"可用片段库"，标记好爆点，剪辑时只做挑选。

### 操作步骤
1. 把漫剧原片按"集"导入素材库（推荐飞书多维表格，字段设计见 `03_素材表格字段模板.md`）。
2. 通读/快看每一集，把**候选爆点片段**的时间码记下来（起止时间）。
3. 每个候选片段用「五维评分模型」打分（见下方专章），总分 ≥3.5 才入库。
4. 给每个片段打标签：`剧名 / 集数 / 爆点类型 / 燃点等级 / 授权状态`。

> 无解说模式下，「节奏卡点」和「视觉冲击」两项的实际权重建议再提高一些——因为没有解说兜底，画面和节奏必须自己扛住全程。可在表格里把这两项的原始分各 +0.5 后再算总分（上限 5）。

### 素材命名规范
```
剧名_集数_爆点类型_燃点等级_起始秒数
例：剑尊_EP12_反转_S_0380
```

### 爆点分析专章（五维评分模型）

每维 1-5 分，按权重加权求和 = 总分（满分 5.0）。

| 维度 | 权重 | 打什么 |
|---|---|---|
| 情绪峰值 | 30% | 角色是否有强烈哭/怒/爽/反转瞬间，情绪张力是否拉满 |
| 悬念钩子 | 25% | 前 3 秒能否制造"然后呢"的追问，是否留悬念 |
| 视觉冲击 | 20% | 大场面、特效、快动作、特写、色彩冲击 |
| 节奏卡点 | 15% | 鼓点是否密集、镜头切换是否干脆、能否踩上拍 |
| 传播潜力 | 10% | 是否有梗点/争议点/金句，是否容易被评论转发 |

**计算公式**
```
总分 = 情绪峰值×0.30 + 悬念钩子×0.25 + 视觉冲击×0.20
     + 节奏卡点×0.15 + 传播潜力×0.10
```

**评级与用法**
- **S 级 ≥ 4.2**：放开头 3 秒钩子，或全片最高潮的爆点
- **A 级 3.5-4.2**：高燃卡点连切的主力素材
- **B 级 3.0-3.5**：铺垫过渡段填充
- **< 3.0**：淘汰，不入库

### 把素材交给我的方式
你可以直接把以下任意一种丢给我，我按上表逐段出「爆点清单」（含时间点、五维打分、总分、建议用法）：
- 漫剧原片视频文件（我用抽帧 + 语音转写分析）
- 截图 / 分镜图（我用画面分析）
- 台词文本 / 剧情梗概（我用文本分析）
- 或直接把片段的时间码列表发我，我给打分建议

## 工位② AI 批量文案（无解说模式：以字幕金句为核心）

**目的**：一次生成 10 条的钩子标题、**字幕金句**、话题标签。不出解说词，字幕就是唯一的"文案层"。

### 字幕金句怎么写（关键）

字幕不是把剧情复述一遍，而是**在卡点瞬间弹出的一句点题话**，8-14 字，配合画面打在情绪上。

示例：
| 画面 | 差的字幕 | 好的字幕 |
|---|---|---|
| 主角被背叛后反杀 | "主角反击了" | "这一刻，他等了三年" |
| 反派放狠话被秒杀 | "反派被打倒" | "狠话说完，人就没了" |
| 身份揭晓 | "她原来是..." | "藏了十二年的名字" |

**原则**：短、狠、留白；用数字和具体细节；不要剧透结尾；一句一屏，跟着鼓点弹。

### 操作步骤
1. 打开豆包 / Kimi / 通义（任选，推荐豆包）。
2. 从 `02_AI提示词模板.md` 复制「钩子标题批量生成」提示词，生成标题。
3. 复制「字幕金句批量生成」提示词，按每个爆点生成 2-3 句候选字幕。
4. 填入本批 10 个爆点片段的信息（爆点类型、情绪、一句剧情）。
5. 一次性生成，人工筛掉平淡的，留下有冲击力的。
6. 用「话题标签生成」模板批量出标签。

### 要点
- 标题写死"竖屏、前 3 秒强钩子、口语化、20 字以内"。
- 字幕金句写死"8-14 字、跟鼓点弹出、一句一屏、不剧透"。
- 每条至少生成 3 个候选标题、2 句候选字幕，择优。
- 话题标签固定 5-8 个：1 个大词 + 3 个精准词 + 2 个热门词。
- **静音可懂测试**：把声音关掉只看字幕，观众能不能看懂剧情？不能就补字幕密度。

## 工位④ 套母版剪辑（核心）

**目的**：这一步决定产能。母版做一次，之后每条只做替换。

### 第一次：制作母版（只做一次）
1. 打开剪映专业版（桌面端），新建草稿。
2. 设置画幅 **9:16**，分辨率 1080×1920，帧率 30fps（卡点更稳用 60fps）。
3. 导入一首 120-140 BPM 的鼓点密集 BGM（**无解说时 BGM 是主情绪推手，选曲比有解说时更关键**）。
4. 选中音频轨道 → 右键 / 顶部菜单 → **「音频 → 节拍 → 自动踩点」**，生成黄色节拍标记点。
5. 铺好音频层次（无解说模式必做）：
   - whoosh：镜头快速转场时
   - impact / 重击：打斗、爆发瞬间
   - riser：高潮前的蓄力爬升
   - boom：最高潮爆点
6. 按时间轴结构铺好骨架（见下方 90 秒黄金结构）。
7. 固化的元素（做成后不再动）：
   - 字幕样式（字体、描边、花字、出现动画）——**无解说时字幕是主要文案层，样式要更醒目**
   - 转场预设（闪白 / 震屏 / 推拉）
   - 滤镜调色（统一 LUT，高对比）
   - 片尾关注引导动画
8. 保存为「母版」，并在云空间备份。

### 90 秒黄金结构（母版骨架）

| 时间 | 段落 | 内容 | 剪辑要点 |
|---|---|---|---|
| 0-3s | 钩子前置 | 最强画面 + 抓人字幕 | S 级爆点，开头即高潮，禁止慢热 |
| 3-10s | 冲突铺垫 | 字幕卡交代人设与冲突 | 用 1-2 句字幕快速交代，不超过 7 秒 |
| 10-70s | 高燃连切 | 卡点快切 A 级爆点 | 每个鼓点切一镜，字幕金句跟点弹出 |
| 70-85s | 高潮反转 | 全片最大爆点 | 爆点 + 特效 + 音乐 drop + 静音反差 |
| 85-90s | 引导互动 | 关注 + 评论钩子 | 提问式字幕，引导评论 |

### 第 N 次：复制母版出片（每条 5-8 分钟）
1. 复制母版草稿 → 重命名。
2. 按爆点清单，把各段素材替换成新片段（拖拽覆盖即可，节拍标记保留）。
3. **替换字幕金句文案（无需替换任何音频）**。
4. 微调：个别镜头长短、卡点对齐（对齐到最近的黄色节拍点）、音效对齐。
5. 预览一遍，导出 1080P / 30fps。

### 卡点对齐技巧
- 镜头切换点尽量落在鼓点标记上，误差不超过 2 帧。
- 高潮处用"静音 0.3 秒 + 爆点"制造反差冲击——**无人声时这个反差更明显，一定要做**。
- 连续快切后安排一个 1 秒长镜头做"呼吸"，避免观众疲劳。
- 字幕出现时机贴在鼓点上，不要提前或滞后半拍。

## 工位⑤ 封面与标题

**目的**：封面决定点击率，标题决定第一印象。

### 操作步骤
1. 用醒图 / 稿定设计做 3-5 套封面模板（竖屏 9:16）。
2. 每套模板固定版式：大字标题 + 人物特写 + 强对比配色。
3. 批量换标题文字和人物图，一次出 10 张。
4. 标题从工位②筛选结果里取最有冲击力的。

### 封面要点
- 主标题不超过 8 个字，用粗体、描边、暖色。
- 人物用 S 级爆点里的特写画面。
- 不同账号用不同配色模板，避免矩阵同质化。

## 工位⑥ 差异化分发（无解说模式：靠 BGM / 字幕 / 配色区分）

**目的**：同一素材剪 3 个版本，多账号错峰发，防同质化限流。

> 有解说时可以靠"换音色"区分账号；**无解说后这招失效**，差异化必须靠下面三项。

### 三版本差异化
| 版本 | 角度 | 字幕风格 | BGM | 配色 |
|---|---|---|---|---|
| V1 | 剧情向 | 叙事型字幕，交代前因后果 | 燃向 120-128 BPM | 红黑 |
| V2 | 燃点向 | 极简，只留金句 | 更快 135+ BPM | 青橙 |
| V3 | 悬念向 | 开头留悬念字幕，中途少字 | 悬疑前奏接 drop | 紫金 |

### 发布策略
- 同一内容不同账号**错峰 30 分钟以上**发布。
- 每账号每天 1-3 条，不要短时间集中灌。
- 标题、话题、封面三处都要做差异，不能只换封面。
- 发布后 30 分钟内回复前排评论，提升互动权重。

## 合规与版权（红线，务必看）

漫剧二创是侵权高发区，矩阵批量运营风险更高，注意：

1. **优先用授权素材**：选择平台官方鼓励二创的剧集，或已获授权的片源。
2. **加入原创表达**：无解说模式下，**原创字幕文案、观点、剪辑节奏就是你的原创表达**——这正是平台判定"二创"而非"搬运"的关键，字幕不能只是原台词照搬。
3. **控制引用比例**：原片引用不宜过长，以"二创"而非"复述"为定位。
4. **标注来源**：按平台要求标注原作出处。
5. **关注平台规则**：抖音/快手对影视二创的规则会调整，定期检查。
6. **授权状态入库**：素材表格里「授权状态」字段必填，`已授权/官方鼓励二创/未确认`，未确认的不要用。

> 提示：以上是操作性提醒，不构成法律意见。商用前建议咨询专业法律人士。

## 附 B：日后想加回解说的切换清单

1. 工位③重新启用：用「解说词批量生成」模板出文案 → TTS 配音（固定 2-3 音色，语速 1.1-1.2 倍）。
2. 工位②恢复解说词生成，字幕金句保留（两者并存效果最好）。
3. 工位④母版新增音频轨：解说人声音量控制在 BGM 之上，BGM 压低到 30-40%。
4. 工位⑥差异化恢复"换音色"这一维度。
5. 质检清单恢复"解说词与画面情绪匹配""BGM 不盖过人声"两项。
6. 90 秒结构中，3-10s 冲突铺垫由字幕卡改回解说交代。
