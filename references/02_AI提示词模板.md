# 漫剧二创 · AI 提示词模板库

> 用法：复制对应模板 → 替换【】里的内容 → 粘贴进豆包 / Kimi / 通义
> 一次生成 10 条，人工择优，不要直接用第一版。
>
> **当前为纯卡点无解说模式**：核心模板是「模板1 钩子标题」+「模板8 字幕金句」+「模板5 话题标签」。
> 模板2（解说词）暂不用；模板4 已按无解说模式改造。

---

## 模板 1：钩子标题批量生成（最高频）

```
你是短视频爆款标题专家，专做漫剧高燃混剪。
请根据以下 10 个剧情爆点，每个生成 3 个标题候选。

要求：
1. 竖屏短视频风格，口语化，20 字以内
2. 前 8 字必须抓人，制造"然后呢"的悬念
3. 用强情绪词：震惊 / 反转 / 燃爆 / 跪了 / 爽 / 绝了
4. 可以用数字、反问、留白制造好奇
5. 不要平铺直叙，不要剧透结局
6. 每个标题后标注用了哪种钩子手法（悬念/反差/数字/反问）

输出格式：
序号 | 爆点概述 | 标题1（手法）| 标题2（手法）| 标题3（手法）

爆点列表：
【粘贴 10 条爆点，每条格式：序号. 剧情一句话 + 爆点类型 + 情绪】
```

【粘贴 10 条爆点】

## 模板 3：爆点识别与分析（把素材交给 AI 打分）

```
你是短视频内容分析师，擅长识别漫剧里的爆点。
我会给你素材（台词文本 / 分镜描述 / 截图画面 / 时间码），
请按五维模型逐段打分。

评分维度（每维 1-5 分）：
- 情绪峰值：角色哭/怒/爽/反转的情绪张力
- 悬念钩子：前 3 秒能否制造"然后呢"
- 视觉冲击：大场面/特效/快动作/特写
- 节奏卡点：鼓点密度/镜头切换是否干脆
- 传播潜力：梗点/争议点/金句

计算公式：
总分 = 情绪×0.30 + 悬念×0.25 + 视觉×0.20 + 节奏×0.15 + 传播×0.10

评级：
- S 级 ≥ 4.2（开头钩子或最高潮）
- A 级 3.5-4.2（卡点连切主力）
- B 级 3.0-3.5（铺垫填充）
- < 3.0（淘汰）

输出格式（表格）：
时间点 | 画面内容 | 情绪 | 悬念 | 视觉 | 节奏 | 传播 | 总分 | 等级 | 建议用法

素材内容：
【粘贴素材】
```

## 模板 4：差异化版本改写（矩阵防限流 · 无解说版）

```
同一部漫剧，我要剪 3 个差异化版本发不同账号。
注意：全程无解说配音，靠 BGM / 字幕风格 / 配色做区分。
请基于以下爆点，生成 3 个版本的差异化方案。

要求：
1. V1 剧情向：叙事型字幕，交代前因后果，燃向 BGM 120-128 BPM，红黑配色
2. V2 燃点向：极简字幕只留金句，快节奏 BGM 135+ BPM，青橙配色
3. V3 悬念向：开头留悬念字幕、中途少字，悬疑前奏接 drop，紫金配色
4. 每个版本的开头钩子字幕必须不同
5. 每个版本给出：开头钩子字幕 / 字幕风格 / BGM 类型 / 配色 / 封面标题

输出格式：
版本 | 开头钩子字幕 | 字幕风格 | BGM 类型 | 配色 | 封面标题

爆点列表：
【粘贴素材】
```

## 模板 8：字幕金句批量生成（无解说模式核心）

```
你是短视频字幕文案专家，专做漫剧高燃卡点混剪的字幕金句。
不出解说配音，字幕是唯一的文案层，必须短、狠、点题。
请为以下 10 个爆点，每个生成 2-3 句候选字幕金句。

要求：
1. 每句 8-14 字，一句一屏，配合鼓点弹出
2. 不是复述剧情，而是"点题"——打在情绪上的一句话
3. 用数字、具体细节、留白制造冲击（例："这一刻，他等了三年"）
4. 不要剧透结局，不要平铺直叙（禁止"主角反击了"这类废话）
5. 口语化、强画面感，看完能脑补出场景
6. 每个爆点的候选字幕风格要有差异，供择优

输出格式：
序号 | 爆点概述 | 字幕1 | 字幕2 | 字幕3

爆点列表：
【粘贴 10 条爆点，每条格式：序号. 剧情一句话 + 爆点类型 + 情绪】
```

## 使用建议

- **当前模式组合**：无解说就用「模板1 标题 + 模板8 字幕金句 + 模板5 话题」三件套，其余按需。
- **批量优先**：一次塞 10 条进去，不要一条一条生成，省时间。
- **择优使用**：AI 第一版通常平庸，让它每个出 3 个候选，你挑最好的。
- **固定人设**：在每个提示词开头加一句"风格参考：XX"，保持账号调性统一。
- **静音可懂**：字幕金句生成后，关掉声音自检——只看字幕能否看懂剧情，不能就补密度。
- **迭代优化**：把效果好的金句喂回去，说"参考这个风格再来 10 个"，越用越准。
- **人工把关**：爆点分析涉及版权素材，AI 打分仅作参考，最终判断在你。
