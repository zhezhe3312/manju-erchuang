五维爆点模型

找爆点的判断标准
维度权重判断标准
情绪峰值30%角色哭 / 怒 / 爽 / 反转 / 打脸的情绪张力
悬念钩子25%前 3 秒能否制造"然后呢"的追看欲
视觉冲击20%大场面 / 特效 / 快动作 / 特写
节奏卡点15%鼓点密度、镜头切换是否干脆
传播潜力10%梗点 / 争议点 / 金句，能不能引发评论
总分 = 情绪×0.30 + 悬念×0.25 + 视觉×0.20 + 节奏×0.15 + 传播×0.10。短剧镜头极密，逐帧看画面不如先做全量语音转写——台词里的情绪爆点比画面更容易定位。

完整工作流

从原片到剪映工程
① 批量预处理→ ② 全角转写 + 爆点分析→ ③ 剪辑方案→ ④ 渲染成片→ ⑤ 剪映工程
1

预处理

原片按"第1集、第2集…"命名，批量抽关键帧 + 导出音频，生成时间码索引。

2

分析爆点

逐集语音转写拿台词，抽帧核对画面，按五维模型打分出带时间码的爆点清单 + 字幕金句。

3

定方案

推荐"整集连播"：一部剧拆上下两部，每部约 7 集整集拼接，剧情零跳跃，成片 15–17 分钟。

4

渲染

按方案截取拼接，烧录金句字幕，输出 1080×1920 竖屏成片。

5

剪映工程

生成每集独立片段 + 金句字幕轨的剪映草稿，逐段可编辑、自己加 BGM 导出。

整集连播的关键：前几集够 10 分钟就不硬塞后面集数；裁集尾"未完待续"前必须先抽帧确认——有的是金字定格可裁 2 秒，有的是叠影转场，裁了会断剧情。
